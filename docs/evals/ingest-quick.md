# Document-ingest eval (quick)

_Generated by `apps/agent/evals/ingest` on 2026-10-20. Do not edit by hand._

Each model reads 12 source documents from the engine scenarios (W-2s, 1099s, SSA-1099, household W-2, energy invoices) and calls Luca's production ingest tools. The tools write facts to a throwaway database. The score is the share of ground-truth fields (from each scenario's `facts.ts`) that the written facts match. Local models run several times per document because their output varies.

A run that makes no ingest call, or that fails with an error, is counted but not scored. Accuracy is the mean over scored runs; the range is the worst and best single run. Latency and output tokens per second depend on the machine as much as the model: the labels say which machine ran each local model.

**Quick tier:** one document per type, 2 runs per local model, for everyday checks. The [full tier](ingest.md) has every document and 5 runs.

Models: Haiku 5.5 (`anthropic/claude-haiku-5-5`), Gemma 4 26b MLX (`ollama/gemma4:26b-mlx`), Gemma 4 e4b (`ollama/gemma4:e4b-mlx`), Gemma 4 e2b (`ollama/gemma4:e2b-mlx`).

## Run it

From `apps/agent`, with Ollama running for the local models:

```bash
npx tsx --env-file=.env evals/ingest/run.ts [model…]          # quick tier
EVAL_PC_OLLAMA_URL=http://<host>:11434/v1 \
  npx tsx --env-file=.env evals/ingest/run.ts --full [model…]   # full tier: Haiku + second-machine models
```
