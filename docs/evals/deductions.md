# Deductions eval

_Generated by `cade/evals/deductions` on 2026-11-11. Do not edit by hand._

Each case is one expense a taxpayer names at the open door of the deductions conversation. The run starts from a filing with a no to every life question, so the open door is the step to take. The model gets the conversation's instructions and tools and the taxpayer's one message. The cases and the reason for each label are in `cade/evals/deductions/cases.ts`.

- **Correct:** the model recorded the expense, each record has the expected outcome (and the expected item, when the expense counts here), the run wrote no amount, and the door stayed open.
- **counts_here:** a deduction item covers the expense.
- **counts_elsewhere:** it is not an itemized deduction, and it may count in a different place on the return.
- **does_not_count:** it is not deductible anywhere on the return.
- **not_sure:** it may count and no item covers it. The CPA gets it.

Models: Haiku 5.5 (`anthropic/claude-haiku-5-5`).

## Run it

From `cade`, with Ollama running for the local models:

```bash
npx tsx --env-file=.env evals/deductions/run.ts --full [model…] [--runs=N]
```

The lite tier is `npm run evals:lite` from the repo root.
