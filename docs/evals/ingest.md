# Document-ingest eval

_Generated by `cade/evals/ingest` on 2026-11-01. Do not edit by hand._

Each model reads 23 source documents from the engine scenarios (W-2s, 1099s, SSA-1099, household W-2, energy invoices) and calls Cade's production ingest tools. The tools write facts to a throwaway database. The score is the share of ground-truth fields (from each scenario's `facts.ts`) that the written facts match. Local models run several times per document because their output varies.

A run that makes no ingest call, or that fails with an error, is counted but not scored. "Missing a form" counts runs that wrote nothing for a form on the document: no call at all, or a skipped call on a consolidated 1099. Accuracy is the mean over scored runs; the range is the worst and best single run. Latency and output tokens per second depend on the machine as much as the model: the labels say which machine ran each local model.

**Full tier:** every scenario document, 5 runs per local model. The lite tier (`npm run evals:lite`) runs one document per type once and publishes no report.

Models: Gemma 4 26b Q4_K_M (`ollama/gemma4:26b`), Gemma 4 31b Q4_K_M (`ollama/gemma4:31b`), Gemma 4 e4b (`ollama/gemma4:e4b`), Haiku 5.5 (`anthropic/claude-haiku-5-5`).

## Run it

From `cade`, with Ollama running for the local models:

```bash
EVAL_PC_OLLAMA_URL=http://<host>:11434/v1 \
  npx tsx --env-file=.env evals/ingest/run.ts --full [model…]   # Haiku and the second-machine models
```

The lite tier is `npm run evals:lite` from the repo root.
