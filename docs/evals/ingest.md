# Document-ingest eval

_Generated by `apps/agent/evals/ingest` on 2026-10-21. Do not edit by hand._

Each model reads 23 source documents from the engine scenarios (W-2s, 1099s, SSA-1099, household W-2, energy invoices) and calls Luca's production ingest tools. The tools write facts to a throwaway database. The score is the share of ground-truth fields (from each scenario's `facts.ts`) that the written facts match. Local models run several times per document because their output varies.

A run that makes no ingest call, or that fails with an error, is counted but not scored. Accuracy is the mean over scored runs; the range is the worst and best single run. Latency and output tokens per second depend on the machine as much as the model: the labels say which machine ran each local model.

**Full tier:** every scenario document, 5 runs per local model. The [quick tier](ingest-quick.md) is a smaller, faster subset.

Models: Haiku 5.5 (`anthropic/claude-haiku-5-5`), Gemma 4 26b Q4_K_M (4090) (`ollama/gemma4:26b`), Gemma 4 31b Q4_K_M (4090) (`ollama/gemma4:31b`), Gemma 4 e4b (4090) (`ollama/gemma4:e4b`).
