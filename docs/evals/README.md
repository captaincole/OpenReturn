## Review

Each case runs the production review-decision workflow on one AI decision, in a correct and a wrong version. ## Ask

Each case asks one tax-code question through the production Ask The Tax Code pipeline (query formulator, hybrid retrieval, answerer, citation check). The flow score is the share of correct runs: the covered / partial / not-covered label is right, the answer cites the labeled passage, and it states every key fact. The capabilities show where runs went wrong: Coverage (the label is right, including a question the library cannot answer), Grounding (an answer cites the labeled passage), Retrieval (the search, from the model's own queries, found it) and Facts (the answer states the key amount).
