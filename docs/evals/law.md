# Law search eval

_Not reviewed by a person yet: agents wrote and checked these cases. Use the scores for development only._

Each case runs its queries (the statute's words, as an agent writes them after it read the IRS instructions) through the law search, 8 hits per query, and merges the hits by best rank. No model call: the vector leg embeds the queries with the local Ollama model. The cases are in `canon/evals/law/cases.json`.

- **Section hit:** one of the top 8 merged hits is in a section the case expects.
- **Path hit:** for a case with `expectPath`, one of the top 8 hits is that subdivision, is inside it, or is the parent block that prints it.
