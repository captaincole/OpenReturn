# Review-judge eval

_Generated by `apps/agent/evals/review` on 2026-10-21. Do not edit by hand._

Each case seeds facts and one AI decision, then runs the production review-decision workflow (query formulator, risk assessor, rule judge, hybrid retrieval over the IRS corpus). Every decision has a correct version and a wrong one. The cases and their expected authority are in `apps/agent/evals/review/cases.ts`.

- **Verdict correct:** the workflow's verdict matches the expected one.
- **Grounded:** on a correct decision, the judge says `accurate` and cites at least one labeled block for each rule.
- **Authority retrieved:** the gather step found a labeled block at all. A miss here is a retrieval problem, not a judge problem.
- **Cited unretrieved ids:** the judge cited an id the run never retrieved (a fact key or a made-up block id). The workflow should only store retrieved blocks.

Models: Gemma 4 31b Q4_K_M (`ollama/gemma4:31b`), Gemma 4 26b Q4_K_M (`ollama/gemma4:26b`), Haiku 5.5 (`anthropic/claude-haiku-5-5`).
