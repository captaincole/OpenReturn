# Ask The Tax Code eval

_Generated by `canon/evals/ask` on 2026-10-23. Do not edit by hand._

Each case asks one question through the production Ask pipeline (query formulator, hybrid retrieval over the IRS/FTB corpus, answerer, citation check). The cases, their expected passages and the facts each answer must state are in `canon/evals/ask/` (`cases.ts` and the tier files).

Three tiers: (1) one rule, one obvious passage; (2) generally accepted answers that take a closer read or two passages; (3) two or more passages, usually federal and California. Each tier has 6 standard questions (tier 3 has 7), 2 that assert a wrong amount or rule the answer must correct (false premise; tier 3 has 3), and 2 the library cannot support (insufficient info: the right answer says not covered, or partial). Coverage is about the library: a question about the taxpayer's own numbers is covered when the passages give every rule and amount needed (the answer may state the rule instead of computing the total), and a fact the taxpayer left out does not make it partial.

- **Correct:** the coverage label is right, the answer cites a labeled passage for each rule (on a question the library covers), and it states every key fact. This is the headline score; the other columns show which part failed.
- **Covered but wrong:** the answer says the library covers the question, but the run is not correct. This is the confidently wrong answer.
- **Coverage right:** the answer's covered / partial / not-covered label is one the case accepts.
- **Grounded:** on a question the library covers, the answer cites a labeled passage for each rule.
- **Authority retrieved:** the search, from the formulator's own queries, found a labeled passage at all. A miss here is a retrieval problem, not an answerer problem.
- **Facts stated:** the answer states the key amount (any accepted spelling).

Models: Gemma 4 31b Q4_K_M (`ollama/gemma4:31b`), Gemma 4 26b Q4_K_M (`ollama/gemma4:26b`), Gemma 4 e4b (`ollama/gemma4:e4b`), Haiku 5.5 (`anthropic/claude-haiku-5-5`).

## Run it

From `canon`, with Ollama running (retrieval embeds queries locally):

```bash
npx tsx --env-file=.env.development evals/ask/run.ts <model-substring> --full [--runs=N] [--case=…]
```

The lite tier is `npm run evals:lite` from the repo root.
