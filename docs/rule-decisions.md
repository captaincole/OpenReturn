# Rule decisions

This page lists each tax rule that someone had to decide, because the official texts did not settle it. It is the place to start a discussion with a tax professional.

Each row was checked against the text of the Internal Revenue Code in the law library on 2026-11-25. The last column gives the subdivision and what it says about the decision: it supports it, contradicts it, is silent or leaves it to regulations, or is not in the library. `docs/law-findings.md` quotes each passage with its block id. A contradiction does not change a decision: a person decides it.

Who decides (see `CLAUDE.md`, "When two official texts conflict, the code records the decision"):

- The author of the rule decides when two official texts point different ways, or when a line can be read two ways. The author follows the principles below and adds the row. No pull request waits for it.
- A person decides when the choice changes a pattern in the repository: a source of data that every form then uses, what an input document with no official form looks like, or how facts, forms or the corpus work.

Each decision below also sits in the code, in a comment that starts with `DECISION (<date>):` above the rule that applies it. `grep -rn "DECISION (" engine/src` lists them. When you add a decision, add the comment and one row here in the same pull request.

## Principles that came out of the decisions

- **A form's own instructions decide how that form is filled.** When the instructions of form A describe a line of form B in another way, form B's instructions win.
- **A guide written for one group applies to that group.** Publication 225 is the farmer's tax guide. It governs a farm's forms. On every other form, the form's own instructions decide.
- **The form's arithmetic wins over a sentence that breaks it.** When a sentence in the instructions gives an amount that the form's own lines cannot produce, the engine follows the lines.
- **A person does not pick the better number item by item.** Where the IRS accepts more than one method, the engine applies one rule the same way every time.
