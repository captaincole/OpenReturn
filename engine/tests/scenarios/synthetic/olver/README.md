## What it covers

  8582 does not file and Schedule E line 22 takes E's loss in full.

  files for D's carryover. Line 3 is income, so every loss is allowed and
  Parts II, III and VI to VIII stay blank.
- F is a self-rental with net income: nonpassive, on the Schedule E worksheet only.
- Schedule CA (540) line 5 column B from FTB 3801 line 2(e).
